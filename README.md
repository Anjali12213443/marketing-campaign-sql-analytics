# Marketing Campaign Performance Analysis (SQL)

## Overview
This project analyzes marketing campaign performance using SQL by calculating key KPIs such as ROI, CTR, and conversion rate.

![SQL](https://img.shields.io/badge/SQL-Database-blue)
![SQLite](https://img.shields.io/badge/SQLite-Lightweight%20DB-lightblue)
![Business Intelligence](https://img.shields.io/badge/BI-KPI%20Analysis-green)


## Tools Used
- SQLite
- DB Browser for SQLite
- SQL

## Key Insights
- Email campaigns generated the highest ROI
- Discount campaigns showed strong conversion performance
- Social media campaigns had lower ROI relative to cost

## Files
- create_tables.sql: Database schema
- insert_data.sql: Sample dataset
- kpi_analysis.sql: KPI calculations
